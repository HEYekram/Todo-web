# Todo App 📝

A simple and responsive Todo App built with **HTML, CSS, and Vanilla JavaScript**. This project is being developed as a hands-on learning project to practice frontend web development fundamentals.

## 🚀 About the Project

The goal of this project is to build a task management application where users can organize their daily activities, track completed tasks, and save their tasks in the browser.

## ✨ Planned Features

- [ ] Add new tasks
- [ ] Mark tasks as completed
- [ ] Delete tasks
- [ ] Display the list of tasks
- [ ] Show the number of remaining tasks
- [ ] Clear completed tasks
- [ ] Save tasks using browser Local Storage
- [ ] Responsive design for mobile and desktop devices

## 🛠️ Technologies Used

- **HTML5** — Structure and semantic markup
- **CSS3** — Styling and responsive layouts
- **JavaScript (Vanilla)** — Application logic and interactivity
- **Local Storage** — Persistent task storage in the browser

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your repository's actual clone URL.

### 2. Open the project

Open the project folder in Visual Studio Code.

### 3. Run the application

Open `index.html` in your browser, or use the Live Server extension in VS Code for local development.
